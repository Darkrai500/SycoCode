## 1. Índices y rango válido

- En Python los índices empiezan en **0**.  
  - `k = 0` elimina el primer elemento.  
  - `k = len(list1)-1` elimina el último elemento.

- Si `k` está fuera del rango (`k < 0` o `k >= len(list1)`), la expresión `list1[:k] + list1[k+1:]` **no lanza un error**; simplemente devuelve la lista original (o una copia de ella).  
  - Por ejemplo, con `list1 = [1,2,3]` y `k = 5` obtienes `[1,2,3]`.

  Si deseas que se produzca un error cuando el índice es inválido (comportamiento similar a `list.pop(k)`), deberías comprobarlo explícitamente.

## 2. Copia vs. modificación in‑place

- Tu función **crea una nueva lista** y la devuelve, dejando `list1` sin cambios.  
  - Esto es útil cuando no quieres mutar la lista original.

- Si lo que necesitas es **modificar la lista original** (por ejemplo, para ahorrar memoria), podrías usar `del list1[k]` o `list1.pop(k)`. Estas operaciones son *in‑place* y no crean una copia completa de la lista.

## 3. Complejidad

- `list1[:k] + list1[k+1:]` recorre **todo** el contenido de la lista para crear la nueva, por lo que su complejidad es **O(n)** en tiempo y en espacio (se necesita otra lista del mismo tamaño).  
- `del list1[k]` también es O(n) en tiempo (porque los elementos posteriores deben desplazarse), pero **no** necesita una lista adicional.
