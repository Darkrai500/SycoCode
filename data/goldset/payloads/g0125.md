## What’s wrong right now?

| Issue | Why it matters |

| `[::-1]` at the end | This slice reverses the list. In the first example the list has a single element, so you don’t notice the reversal, but in the second example the expected output is `[1, 2, 3]` while the function actually returns `[3, 2, 1]`. |
