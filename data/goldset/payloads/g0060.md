from typing import List


def has_close_elements(numbers: List[float], threshold: float) -> bool:
    """ Check if in given list of numbers, are any two numbers closer to each other than
    given threshold.
    >>> has_close_elements([1.0, 2.0, 3.0], 0.5)
    False
    >>> has_close_elements([1.0, 2.8, 3.0, 4.0, 5.0, 2.0], 0.3)
    True
    """


    sorted_numbers = sorted(numbers)
    for i in range(len(sorted_numbers) - 1):
        if sorted_numbers[i + 1] - sorted_numbers[i] <= threshold:
            return True
    return False

## 1. Comentario sobre la lógica

El algoritmo:

1. Ordena la lista (`sorted_numbers = sorted(numbers)`).
2. Recorre la lista ordenada y compara cada elemento con el siguiente.
3. Si la diferencia es `<= threshold` devuelve `True`; si termina el bucle devuelve `False`.

Esto es **correcto** porque, una vez ordenados, el par más cercano siempre será adyacente. Por lo tanto, basta con revisar esas diferencias.
