    """Return true if a given number is prime, and false otherwise.
    >>> is_prime(6)
    False
    >>> is_prime(101)
    True

    True

    True

    if n <= 1: return False

## 1. Cálculo del límite de iteración

[code block omitted]

* **Problema**: Este bucle incrementa `n_sqrt` una a una hasta que su cuadrado supera a `n`.  
  - En el peor de los casos (por ejemplo `n = 10⁹`) se ejecutan ~√n iteraciones, lo cual es innecesariamente lento en Python puro.
  - Además, el valor final de `n_sqrt` es **el entero más pequeño cuyo cuadrado es ≥ n**, es decir, `ceil(sqrt(n))`. Cuando lo usas después en `range(2, min(n_sqrt, n))` el límite superior es `ceil(sqrt(n))`, pero el rango de `range` es **exclusivo**, por lo que el último divisor posible (`floor(sqrt(n))`) nunca se prueba. En la práctica esto no rompe la mayoría de los casos porque el divisor `floor(sqrt(n))` solo es necesario cuando `n` es un cuadrado perfecto (p.ej. `n = 49`). En ese caso tu algoritmo **no detecta** que 49 es compuesto y devolvería `True`.  

  [code block omitted]

* **Solución**: Usa la función de la biblioteca estándar `math.isqrt` (disponible desde Python 3.8) que devuelve `⌊√n⌋` de forma O(1). Luego itera hasta `isqrt(n) + 1` (el `+1` es para que el rango sea inclusivo).
